Plotting Functions – catsim.plot#

Plots of items, item banks, CAT sessions and simulation results, drawn with matplotlib.

The module needs matplotlib, which the plot extra installs: pip install 'catsim[plot]'. Each function takes its data first, as plain catsim objects, and its options as keyword-only arguments, draws on the ax it is given or on the axes of a new figure, and returns the axes it drew on (ADR-0022).

Plots label items by their names in the item bank (ADR-0004), drawn as given: a dollar sign in a name does not start mathtext. An x axis with one tick per item names each item while it has at most 30, the most names that stay apart at matplotlib’s default figure width; a longer one ticks whole numbers, as each function’s description says.

Plots follow the matplotlib style, set with plt.style.use or plt.style.context: its fonts, colours, title size and grid. matplotlib fixes most of an axes’ look when the axes are made, so make ax under the style the plot should take. A second y axis, on the right, draws its spine and no grid.

A plot that takes a label draws one run, item set or session in the next colour of the axes: drawing several on the same axes, each with its label, and calling ax.legend() compares them. A plot that compares estimates with true abilities raises ValueError for a result without them, before any figure is created.

catsim.plot.bank_information(item_bank: ItemBank, *, items: ArrayLike | None = None, se: bool = True, ax: Axes | None = None, title: str | None = None, label: str | None = None) → Axes[source]#

Plot the information of an item bank, or of some of its items, against ability, with its standard error.

The information \(I(\theta)\) is the sum of the items’ information, from -4 to 4. For a whole bank it bounds what a test drawn from it can measure; with items it is the information of that fixed set of items. With se, the standard error \(1/\sqrt{I(\theta)}\) goes on a second y axis, on the right, and each axis takes its curve’s colour. To compare sets of items on one axes, pass se=False and a label with each.

Parameters:
item_bankItemBank

The item bank.

itemsarray-like or None, optional

The positions of the items to sum, distinct integers of item_bank. Default is None, which sums every item of the bank.

sebool, optional

Whether to draw the standard error on a second y axis. Default is True.

axmatplotlib.axes.Axes or None, optional

The axes to draw on. Default is None, which draws on the axes of a new figure.

titlestr or None, optional

The plot title. Default is None, which sets none.

labelstr or None, optional

The information curve’s label, for a legend. Default is None, which sets none.

Returns:
matplotlib.axes.Axes

The axes of the information. The standard error is drawn on their twin, which shares the x axis.

Raises:
TypeError

If an entry of items is not an integer, before any figure is created.

ValueError

If items is empty, repeats an item or names one outside the bank, before any figure is created.

catsim.plot.expected_score(item_bank: ItemBank, *, items: ArrayLike | None = None, ax: Axes | None = None, title: str | None = None, label: str | None = None) → Axes[source]#

Plot the expected proportion of correct responses to an item bank, or to some of its items, against ability.

The proportion is the mean of the items’ characteristic curves, from -4 to 4: the test characteristic curve divided by the number of items, so that sets of any size share one scale, from 0 to 1.

catsim.plot.item_curve(item: int, item_bank: ItemBank, *, kind: PlotType | str = PlotType.ICC, max_info: bool = True, ax: Axes | None = None, title: str | None = None) → Axes[source]#

Plot an item’s characteristic curve, its information curve, or both.

The curves span four units of ability on each side of the item’s difficulty, and a box in the upper left corner gives the item’s name and parameters. With PlotType.BOTH the information curve has its own y axis, on the right, and the two curves take the first two colours of the style.

Parameters:
itemint

The item’s index in item_bank; item_bank.index(name) gives the index of a named item.

item_bankItemBank

The item bank that holds the item’s name and parameters.

kindPlotType or str, optional

Which curves to draw, as a PlotType or its value ("icc", "iic" or "both"). Default is PlotType.ICC.

max_infobool, optional

Whether to mark the ability at which the item gives the most information with a dot on the information curve. Default is True.

axmatplotlib.axes.Axes or None, optional

The axes to draw on. Default is None, which draws on the axes of a new figure.

titlestr or None, optional

The plot title. Default is None, which sets none.

Returns:
matplotlib.axes.Axes

The axes the characteristic curve is on, or those of the information curve for PlotType.IIC.

Raises:
TypeError

If item is not an integer, before any figure is created.

ValueError

If item is not an index of item_bank or kind is neither a PlotType nor one of its values, before any figure is created.

catsim.plot.item_exposure(exposure_rates: NDArray[floating[Any]], item_bank: ItemBank, *, par: str | None = None, hist: bool = False, ax: Axes | None = None, title: str | None = None, label: str | None = None) → Axes[source]#

Plot the items’ exposure rates: from the most to the least exposed, against an item parameter, or as a histogram.

By default the items are sorted from the most to the least exposed, which shows how evenly a run uses its bank and where an exposure cap holds the rates; the x axis names each item, or counts them in a bank of more than 30 items. With par, each item is a point at its value of that parameter, which shows which items a selector favours. With hist=True, the plot counts the items in each range of exposure rates.

Parameters:
exposure_ratesnumpy.ndarray

The exposure rate of each item, in item bank order, such as the value of a SimulationResult’s exposure_rates().

item_bankItemBank

The item bank the rates belong to, which holds the items’ names and parameters.

parstr or None, optional

The item parameter to plot the rates against: "a", "b", "c" or "d". Default is None, which sorts the items from the most to the least exposed.

histbool, optional

Whether to draw a histogram of the rates. Default is False.

axmatplotlib.axes.Axes or None, optional

The axes to draw on. Default is None, which draws on the axes of a new figure.

titlestr or None, optional

The plot title. Default is None, which sets none.

labelstr or None, optional

The rates’ label, for a legend. Default is None, which sets none.

Returns:
matplotlib.axes.Axes

The axes the plot is on.

Raises:
ValueError

If exposure_rates is not one rate per item of item_bank, par is not one of "a", "b", "c" and "d", or par is given with hist=True; always before any figure is created.

catsim.plot.item_person_map(item_bank: ItemBank, thetas: ArrayLike, *, ax: Axes | None = None, title: str | None = None) → Axes[source]#

Plot examinees’ abilities above the axis and, below it, the abilities where the bank’s items inform most.

Both histograms share one \(\theta\) scale and its bins, and each shows shares, so a bank and a population of any sizes compare: the examinees’ bars sum to 1 above the axis and the items’ bars to 1 below it. An item sits at max_info_thetas, which is its difficulty for one- and two-parameter items.

matplotlib.axes.Axes

Plot how many of a run’s sessions administered each number of items.

Each test length has its own bin, drawn as an outline, so several runs drawn on the same axes stay readable over each other. In a variable-length run, the bin at the length cap counts the tests that reached the cap.

catsim.plot.likelihood(session: Session, item_bank: ItemBank, *, true_theta: float | None = None, ax: Axes | None = None, title: str | None = None, label: str | None = None) → Axes[source]#

Plot the likelihood of a session’s responses across abilities, relative to its maximum, with its final estimate.

The curve is the likelihood of the responses to the administered items, divided by its maximum, from -6 to 6, the range catsim’s estimators keep their estimates in. A dashed line in the curve’s colour marks the session’s final estimate and, when it is given, a dotted black line the true ability. Responses that are all correct, or all incorrect, have no maximum inside the range, so their curve rises to its edge.

Parameters:

The session whose responses to plot, such as an entry of SimulationResult.sessions.

item_bankItemBank

The item bank the session’s items come from.

true_thetafloat or None, optional

The examinee’s true ability, marked by a dotted line. Default is None, which marks none.

axmatplotlib.axes.Axes or None, optional

The axes to draw on. Default is None, which draws on the axes of a new figure.

titlestr or None, optional

The plot title. Default is None, which sets none.

labelstr or None, optional

The curve’s label, for a legend. Default is None, which sets none.

Returns:
matplotlib.axes.Axes

The axes the plot is on.

Raises:

If an administered item is not an item of item_bank, before any figure is created.

catsim.plot.metric_by_ability(result: SimulationResult, metric: str = 'rmse', *, levels: bool = False, ax: Axes | None = None, title: str | None = None, label: str | None = None) → Axes[source]#

Plot a run’s metric in each decile of the true ability, or at each distinct true ability, with its error bars.

Each point is a group’s metric at its mean true ability, from the result’s deciles(), or with levels=True from its ability_levels(), which suits designs of a few fixed abilities. The bars span one Monte Carlo standard error on each side, and the bias gets a line at 0.

Parameters:
resultSimulationResult

The run, with its examinees’ true abilities.

metricstr, optional

The metric: "bias", "mse", "rmse", "se" (the mean standard error), "test_length" or "overlap_rate". Default is "rmse".

levelsbool, optional

Whether to group the sessions by distinct true ability rather than by decile. Default is False.

axmatplotlib.axes.Axes or None, optional

The axes to draw on. Default is None, which draws on the axes of a new figure.

titlestr or None, optional

The plot title. Default is None, which sets none.

labelstr or None, optional

The run’s label, for a legend. Default is None, which sets none.

Returns:
matplotlib.axes.Axes

The axes the plot is on.

Raises:
ValueError

If metric is not one of the metrics above, or the result has no true abilities, before any figure is created.

catsim.plot.metric_by_length(result: SimulationResult, metric: str = 'rmse', *, ax: Axes | None = None, title: str | None = None, label: str | None = None) → Axes[source]#

Plot a run’s metric after each number of items administered, with a band of one Monte Carlo standard error.

Every session counts after every number of items: one that stopped earlier counts at its final estimate, so a variable-length run is not judged on its longest tests alone. The metric is the bias, MSE or RMSE of the estimates, which need the true abilities, or their mean standard error.

catsim.plot.session_progress(session: Session, item_bank: ItemBank, *, true_theta: float | None = None, ax: Axes | None = None, title: str | None = None) → Axes[source]#

Plot how a session’s ability estimate and its standard error change as items are administered.

The x axis counts the items administered. While the session has at most 30 items, its ticks name the item given at each step instead, and the initial estimate, at 0, has none, so a session with no items has no ticks. The y axis shows the ability estimate after each response, with a band of one standard error on each side: the error each estimate was recorded with, the one precision-based stoppers judge. An infinite standard error, such as the initial estimate’s, leaves the band out. The difficulty of each administered item and, when it is given, the true ability share the axis.

Parameters:
sessionSession

The session to plot, such as an entry of SimulationResult.sessions.

item_bankItemBank

The item bank the session’s items come from.

true_thetafloat or None, optional

The examinee’s true ability, drawn as a horizontal line, such as an entry of SimulationResult.true_thetas. Default is None, which draws none.

axmatplotlib.axes.Axes or None, optional

The axes to draw on. Default is None, which draws on the axes of a new figure.

titlestr or None, optional

The plot title. Default is None, which sets none.

Returns:
matplotlib.axes.Axes

The axes the plot is on.

Raises:
ValueError

If an administered item is not an item of item_bank, before any figure is created.
