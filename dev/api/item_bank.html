Item Bank#

class catsim.ItemBank(items: NDArray[floating[Any]])[source]#

The calibrated items of a test, with the values derived from their parameters.

A bank checks every parameter when it is built and caches the values that depend only on the parameters, such as each item’s point of maximum information. Its arrays are read-only, so the cached values cannot go stale. Build a bank from an item matrix, or draw one with generate().

Parameters:
itemsnumpy.ndarray

Item parameter matrix, one row per item, with columns [a, b, c, d]. A matrix with one column is read as [b], two as [a, b] and three as [a, b, c], filled with \(a = 1\), \(c = 0\) and \(d = 1\); a 1-D array is one item.

Attributes:
itemsnumpy.ndarray

Get the item parameter matrix.

n_itemsint

Get the number of items in the bank.

max_info_thetasnumpy.ndarray

Get the cached theta values where items have maximum information.

max_info_valuesnumpy.ndarray

Get the cached maximum information values for each item.

Raises:
ValueError

If the matrix does not have 1 to 4 columns, has no items, or has a parameter that is NaN, infinite or outside \(a > 0\) and \(0 \leq c < d \leq 1\).

TypeError

If items is not a numpy.ndarray.

Examples

>>> import numpy as np
>>> from catsim import ItemBank
>>> ItemBank(np.array([[1.0, 0.0, 0.0, 1.0], [1.2, -0.5, 0.1, 1.0]]))
ItemBank(n_items=2, model=3PL)
>>> ItemBank.generate(100, model="3PL", rng=7)
ItemBank(n_items=100, model=3PL)

classmethod generate(n_items: int, model: IrtModel | str = IrtModel.PL4, corr: float = 0.0, rng: int | Generator | None = None) → Self[source]#

Draw a bank of n_items items of one logistic model.

The parameters the model varies are drawn from these distributions; the others are \(a = 1\), \(c = 0\) and \(d = 1\).

  • discrimination: normal with mean 1.2 and standard deviation 0.25, truncated to positive values;

  • difficulty: standard normal, with correlation corr to the discrimination;

  • guessing parameter: normal with mean 0.25 and standard deviation 0.02, clipped at 0;

  • upper asymptote: uniform on [0.94, 1].

The first three are the distributions of the simulated 3PL banks of Barrada et al. [2010] (p. 445); the upper asymptote’s is catsim’s own.

Parameters:
n_itemsint

Number of items.

modelIrtModel or str, optional

The logistic model of the items, an IrtModel or its name in any case (“3pl”). Default is IrtModel.PL4.

corrfloat, optional

Correlation between discrimination and difficulty, ignored for IrtModel.PL1. Default is 0.

rngint, numpy.random.Generator or None, optional

Where the parameters are drawn from. None, the default, draws fresh randomness, so every call gives another bank. An int seeds a new generator, so the same seed gives the same bank. A generator is drawn from as is, and the call advances it.

Returns:
ItemBank

The generated bank.

Raises:
ValueError

If model is neither an IrtModel nor one of the names “1PL”, “2PL”, “3PL” and “4PL”, in any case.

Examples

>>> bank = ItemBank.generate(100, model="3PL", corr=0.3, rng=7)
>>> bank.n_items
100
>>> bank.model
<IrtModel.PL3: '3PL'>
get_items(indices: ArrayLike) → NDArray[floating[Any]][source]#

Return the parameter rows of the given items, in the order of indices.

Any sequence of item indices is read as a list of items, so a tuple such as a context’s administered_items gives its rows and an empty one gives no rows, whereas bank[(1, 2)] is one parameter (row 1, column 2) and bank[()] is every item.

Parameters:
indicesarray-like of int

Item indices: a list, tuple or integer array, possibly empty.

Returns:
numpy.ndarray

A copy of the rows, shape (len(indices), 4).

Examples

>>> bank = ItemBank.generate(5, rng=0)
>>> bank.get_items((1, 2)).shape
(2, 4)
>>> bank.get_items(()).shape
(0, 4)

class catsim.IrtModel(*values)[source]#

The logistic model of an item bank, named after the number of parameters its items vary.

A member equals its name, so IrtModel("3PL") is IrtModel.PL3 and either can be passed where a model is expected. A 1PL (Rasch) bank has one discrimination for every item, \(c = 0\) and \(d = 1\); a 2PL bank varies the discrimination, a 3PL bank also the guessing parameter \(c\), and a 4PL bank also the upper asymptote \(d\).

Examples

>>> IrtModel("3PL") is IrtModel.PL3
True
