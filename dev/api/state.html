Session State#

class catsim.CatSessionState(session_id: Hashable, estimates: list[Estimate], true_theta: float | None = None, administered_items: list[int] = <factory>, responses: list[bool] = <factory>, stop_reason: StopReason | None = None, excluded_items: list[int] = <factory>)[source]#

Mutable runtime state for a single examinee CAT session.

start_session() creates a session and the engine advances it in place. An application that saves a session restores it by passing the saved fields back; a restored session’s estimates are trusted as given. A session runs while stop_reason is None.

Parameters:
session_idHashable

Whatever hashable value the application identifies the session by, such as an int, a str or a UUID.

estimateslist of Estimate

The initial estimate, which start_session() records with an infinite standard error and no evaluations, then the Estimate the estimator returned for each response. The last entry is the current estimate.

true_thetafloat or None, optional

True ability of a simulated examinee. Default is None.

administered_itemslist of int, optional

Indices of the items given so far, in order. Default is an empty list.

responseslist of bool, optional

The responses to the administered items, in the same order. Default is an empty list.

stop_reasonStopReason or None, optional

Why the session ended, or None while it runs. The reason’s string value, as a saved session holds it, is accepted. Default is None.

excluded_itemslist of int, optional

Items the session must not be given although it has not had them. An application may fill it before the first item, for example with the items the examinee saw in an earlier attempt; during the test it only grows, as the engine adds the items its exposure control declines. Removing an item from it during the test is not supported. The engine passes the items to every strategy and raises ExcludedItemError for a response to one. Their indices are checked against the item bank at the session’s next step. Default is an empty list.

Raises:
ValueError

If the session does not have one response per administered item and one more estimate than responses, if excluded_items repeats an item or holds an administered one, or if stop_reason is not a StopReason value.

TypeError

If an entry of estimates is not an Estimate, or an entry of administered_items or excluded_items is not an integer.

class catsim.StopReason(*values)[source]#

Why a CAT session ended.

STOPPER means the engine’s stopper was satisfied by the session’s current state. NO_ITEMS means the selector had no item to offer, which is not necessarily the end of the item bank: a selector that follows a fixed list or works through strata can run out first.

class catsim.ExposureTracker(n_items: int, counts: npt.ArrayLike | None = None, n_sessions: int = 0, *, proposals: npt.ArrayLike | None = None)[source]#

Count item administrations, proposals and sessions across a run, and give sessions their exposure rates.

One tracker is shared by every session of a run or of a live deployment, through RunContext, and the engine updates it. counts holds each item’s administrations so far, those of sessions still in progress included, proposals its administrations plus the times the engine’s exposure control declined it, and n_sessions the number of sessions started. A session proposes an item at most once, so neither count can exceed n_sessions.

A session is selected against each item’s administrations divided by the number of other sessions started so far. With sessions run one after another, as a simulation runs them, that is the share of the examinees tested before the current one; the first session sees every rate at 0. Sessions that run side by side, as in a live deployment, see each other’s administrations as they happen.

A new tracker starts from zero. An application that must keep the exposure across restarts saves counts, proposals and n_sessions and passes them back to rebuild the tracker.

Parameters:
n_itemsint

Number of items in the bank.

countsarray-like of int or None, optional

Each item’s administrations so far, as a saved tracker’s counts holds them. The tracker keeps a copy. Default is None, for no administrations.

n_sessionsint, optional

Sessions started so far, as a saved tracker’s n_sessions holds them. Default is 0.

proposalsarray-like of int or None, optional

Each item’s proposals so far, as a saved tracker’s proposals holds them. The tracker keeps a copy. Default is None, which takes a copy of counts, the proposals of a run without an exposure control.

Raises:
ValueError

If counts or proposals does not hold one count per item or holds a negative count, if an item has more administrations than proposals or more proposals than n_sessions, or if n_sessions is negative.

TypeError

If counts or proposals holds a value that is not an integer, or n_sessions is not an integer (a bool included).

rates() → FloatArray[source]#

Return the exposure rates a session in progress is selected against.

Each item’s administrations are divided by the sessions started so far other than the one asking, so a session never counts itself. Its own administrations stay in the counts, but only for items it has already administered and will not be offered again; for those the rate can exceed 1.

Returns:
numpy.ndarray

A new array with one rate per item; all zero while at most one session has started. This is not the run’s final exposure, which exposure_rates gives.
