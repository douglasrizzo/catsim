CAT Engine#

class catsim.CatEngine(item_bank: ItemBank, initializer: BaseInitializer, selector: BaseSelector, estimator: BaseEstimator, stopper: BaseStopper, *, exposure_control: BaseExposureControl | None = None)[source]#

Engine for stepwise CAT execution on one item bank.

Every session the engine runs is tested on its item bank: the item indices a session records, and the exposure tracker of the run, refer to that bank. An application with several banks builds one engine per bank.

Parameters:
item_bankItemBank

The calibrated items the engine’s sessions are tested on.

initializerBaseInitializer

Gives each session its initial ability estimate.

selectorBaseSelector

Chooses the next item.

estimatorBaseEstimator

Updates the ability estimate after each response.

stopperBaseStopper

Decides when a session has ended.

exposure_controlBaseExposureControl or None, optional

Decides whether to administer each item the selector proposes; a declined item is excluded from the session for the rest of its test. Default is None, which administers every proposed item.

Raises:
TypeError

If item_bank is not an ItemBank.

apply_response(state: CatSessionState, item_id: int, *, response: bool, context: RunContext) → CatStepResult[source]#

Record the examinee’s response to an item, update the estimate and check the stopper.

The step is atomic: the inputs are validated, and the new estimate and the stopper’s decision are computed, before the session or the exposure tracker change, so a step that raises leaves both as they were.

Parameters:
stateCatSessionState

The session that administered the item. It must not be stopped.

item_idint

Index of the administered item, usually the one select_next() returned.

responsebool

Whether the examinee answered the item correctly; a bool or numpy.bool_.

contextRunContext

Runtime services of the run; the item’s administration is recorded in its exposure tracker, if it has one.

Returns:
CatStepResult

The administered item, the response, the updated estimate and whether the session stopped.

Raises:
ExcludedItemError

If the item is in the session’s excluded_items.

ValueError

If the session has stopped, the item index is outside the bank or the item was already administered in this session.

TypeError

If the item index is not an integer, the response is not a bool or numpy.bool_, or the estimator returns something other than an Estimate.

property item_bank: ItemBank#

Return the item bank the engine’s sessions are tested on.

select_next(state: CatSessionState, context: RunContext) → int | None[source]#

Select the next item to administer, or end the session.

It returns None once the session has ended, so a loop needs no other check. The stopper is consulted here only before the first response; after that, apply_response() consults it. The items the exposure control declines join the session’s excluded_items and the tracker’s proposals, unless the selection raises, so save the session after this call too. Each call selects anew, so a second call may return another item or end the session: keep the returned id until its response arrives. See Live CAT Sessions.

Parameters:
stateCatSessionState

The session to continue. It is marked stopped when this method returns None for it.

contextRunContext

Runtime services of the run: the random generator and, optionally, the exposure tracker.

Returns:
int or None

Index of the next item to administer. None when the session has ended: it was already stopped (and is left untouched), its stopper is satisfied (reason StopReason.STOPPER), or the selector has no item to offer, or none the exposure control accepts (reason StopReason.NO_ITEMS).

Raises:
ExcludedItemError

If the selector proposes an item the session excluded.

ValueError

If the selector proposes an item outside the bank or one already administered.

Examples

>>> import numpy
>>> from catsim import CatEngine, ItemBank, RunContext
>>> from catsim.estimation import EAPEstimator
>>> from catsim.initialization import FixedPointInitializer
>>> from catsim.selection import MaxInfoSelector
>>> from catsim.stopping import MaxLengthStopper
>>> bank = ItemBank.generate(50, rng=0)
>>> engine = CatEngine(bank, FixedPointInitializer(0.0), MaxInfoSelector(), EAPEstimator(), MaxLengthStopper(5))
>>> context = RunContext(rng=numpy.random.default_rng(0))
>>> state = engine.start_session("examinee-1", context)
>>> while (item_id := engine.select_next(state, context)) is not None:
...   step = engine.apply_response(state, item_id, response=bool(bank.difficulty[item_id] < 0), context=context)
>>> state.administered_count, state.stop_reason
(5, <StopReason.STOPPER: 'stopper'>)

class catsim.RunContext(rng: Generator, exposure_tracker: ExposureTracker | None = None)[source]#

Runtime services shared by CAT sessions in one run.

Parameters:
rngnumpy.random.Generator

The run’s random generator, which the initializer, the selector, the exposure control and the response provider draw from.

exposure_trackerExposureTracker or None, optional

Counts sessions, item administrations and proposals across the run and gives selectors the exposure rates their r_max cap is checked against. Without one, selectors get no rates and apply no cap. Default is None.

class catsim.ResponseProvider(*args, **kwargs)[source]#

Source of the examinee’s responses for CatEngine.step() and CatEngine.run_session().

SimulatedResponseProvider draws them from a simulated examinee’s true ability; an application that steps sessions itself can wrap whatever collects real answers.
