CAT Engine#

class catsim.CatEngine(item_bank: ItemBank, initializer: BaseInitializer, selector: BaseSelector, estimator: BaseEstimator, stopper: BaseStopper, *, exposure_control: BaseExposureControl | None = None)[source]#

The configuration of a computerized adaptive test, and the steps that run it.

An engine never changes. Its three step methods take a Session and return a new one, and keep nothing between calls (ADR-0006): start() begins a session, select() proposes its next item and answer() records the response to it. The caller keeps the sessions, the item on screen and the exposure counts. A session is tested on the engine’s item bank: its item indices are indices of that bank.

The stopper is asked once per state of the session: by start() about the initial one and by answer() about each state after a response. A satisfied stopper ends the session with StopReason.STOPPER, and a selector with no item to offer ends it in select() with StopReason.NO_ITEMS (ADR-0010). The inputs of each step are checked where they enter (ADR-0009).

The Embedding catsim guide runs a test step by step.

Parameters:
item_bankItemBank

The calibrated items the engine’s sessions are tested on.

initializerBaseInitializer

Gives each session its initial ability estimate.

selectorBaseSelector

Proposes the next item.

estimatorBaseEstimator

Updates the ability estimate after each response.

stopperBaseStopper

Decides when a session has ended.

exposure_controlBaseExposureControl or None, optional

Decides whether to administer each item the selector proposes; a declined item is excluded from the session for the rest of its test (ADR-0011). Default is None, which administers every proposed item.

Raises:
TypeError

If item_bank is not an ItemBank.

Examples

A test of five items, whose examinee answers every item easier than average correctly:

>>> import numpy
>>> from catsim import CatEngine, ItemBank
>>> from catsim.estimation import EAPEstimator
>>> from catsim.initialization import FixedPointInitializer
>>> from catsim.selection import MaxInfoSelector
>>> from catsim.stopping import MaxLengthStopper
>>> bank = ItemBank.generate(50, rng=0)
>>> engine = CatEngine(bank, FixedPointInitializer(0.0), MaxInfoSelector(), EAPEstimator(), MaxLengthStopper(5))
>>> rng = numpy.random.default_rng(0)
>>> session = engine.start(rng=rng)
>>> while True:
...   selection = engine.select(session, rng=rng)
...   session = selection.session
...   if selection.item is None:
...     break
...   session = engine.answer(session, selection.item, bool(bank.difficulty[selection.item] < 0), rng=rng)
>>> len(session.administered_items), session.stop_reason
(5, <StopReason.STOPPER: 'stopper'>)
answer(session: Session, item: int, response: bool, *, rng: int | Generator | None) → Session[source]#

Record the response to an item, update the estimate and ask the stopper about the new state.

Parameters:
sessionSession

The running session the item was administered in, usually selection.session.

itemint

Index of the administered item, usually selection.item.

responsebool

Whether the examinee answered the item correctly: a bool, a numpy.bool_ or the integer 0 or 1.

rngint, numpy.random.Generator or None

The random source of the estimator’s and the stopper’s contexts: a generator, used as is, a seed, or None for fresh entropy (ADR-0013). No built-in estimator or stopper draws from it.

Returns:
Session

The session with the item, the response and the estimator’s estimate added. Its stop_reason is StopReason.STOPPER if the stopper is satisfied by the new state.

Raises:
TypeError

If session is not a Session, item is not an integer, the response is neither a Boolean nor an integer, or the estimator returns something other than an Estimate.

ValueError

If the session has stopped, an item of the session or item is outside the bank, the session has had item, or an integer response is not 0 or 1.

ExcludedItemError

If the session excluded item.

context(session: Session, *, rng: int | numpy.random.Generator | None = None, exposure_rates: FloatArray | None = None) → StepContext[source]#

Return what the strategies may read about a session as it stands.

It is the context the selector reads for the session’s next proposal and the stopper read about its last state: the session’s items, responses, excluded items and current estimate with its standard error. A StopRule asked with it tells which of its criteria hold.

Parameters:
sessionSession

The session.

rngint, numpy.random.Generator or None, optional

The context’s random source: a generator, used as is, a seed, or None for fresh entropy (ADR-0013). Default is None.

exposure_ratesnumpy.ndarray or None, optional

The context’s exposure rates, one value in [0, 1] per item. Default is None.

Returns:
StepContext

The session’s bank, items, responses, excluded items, current estimate and standard error, with the generator and the exposure rates.

Raises:
TypeError

If session is not a Session, or the exposure rates are not real numbers.

ValueError

If an item of the session is outside the bank, or the exposure rates are not one value in [0, 1] per item.

Examples

>>> from catsim import CatEngine, ItemBank, simulate
>>> from catsim.estimation import EAPEstimator
>>> from catsim.initialization import FixedPointInitializer
>>> from catsim.selection import MaxInfoSelector
>>> from catsim.stopping import MaxLengthStopper, StandardErrorStopper, StopRule
>>> rule = StopRule(StandardErrorStopper(0.2), MaxLengthStopper(5))
>>> bank = ItemBank.generate(50, rng=0)
>>> engine = CatEngine(bank, FixedPointInitializer(0.0), MaxInfoSelector(), EAPEstimator(), rule)
>>> session = simulate(engine, true_thetas=[0.0], rng=0).sessions[0]
>>> rule.satisfied(engine.context(session))
(MaxLengthStopper(max_items=5),)
select(session: Session, *, rng: int | numpy.random.Generator | None, exposure_rates: FloatArray | None = None) → Selection[source]#

Propose the next item of a session, or end it when the selector has none to offer.

The selector proposes items until the exposure control accepts one; each item it declines joins the session’s excluded items (ADR-0011). Every call selects anew, and a selector may draw at random, so a second call on the same session may propose another item: keeping the item on screen until its response arrives is the caller’s.

Parameters:
sessionSession

The session, which select does not change.

rngint, numpy.random.Generator or None

The random source of the selector and the exposure control: a generator, used as is, a seed, or None for fresh entropy (ADR-0013).

exposure_ratesnumpy.ndarray or None, optional

Each item’s exposure rate, one value in [0, 1] per item of the bank, which selectors compare with their r_max cap; the caller computes them from the counts it keeps (ADR-0012). Default is None, under which no cap applies.

Returns:
Selection

The item to administer and the session to answer it in, with the items the control declined. For a session that has stopped, no item and that same session; for a selector with no item to offer, or none the control accepts, no item and the session ended with StopReason.NO_ITEMS.

Raises:
TypeError

If session is not a Session, the exposure rates are not real numbers or the selector proposes an index that is not an integer.

ValueError

If an item of the session is outside the bank, the exposure rates are not one value in [0, 1] per item, or the selector proposes an item outside the bank or one the session has had.

ExcludedItemError

If the selector proposes an item the session excluded.

start(*, rng: int | numpy.random.Generator | None, excluded_items: Iterable[int] = ()) → Session[source]#

Begin a session at the initializer’s estimate, and ask the stopper about it.

Parameters:
rngint, numpy.random.Generator or None

The random source of the initializer and of the stopper’s context: a generator, used as is, a seed, or None for fresh entropy (ADR-0013).

excluded_itemsIterable[int], optional

Items the session must not be given, such as those the examinee saw in an earlier attempt or those a recorded examinee has no response to (ADR-0011). Default is no items.

Returns:
Session

A session with no items, whose estimates hold the initial one, with an infinite standard error and no evaluations. Its stop_reason is StopReason.STOPPER if the stopper is satisfied before any item, and None otherwise.

Raises:
TypeError

If an excluded item is not an integer.

ValueError

If an excluded item is outside the bank or repeats, or the initializer’s estimate is not finite.

class catsim.Selection(item: int | None, session: Session, declined: tuple[int, ...])[source]#

What CatEngine.select() returns: the item to administer, the session and the items declined.

Parameters:
itemint or None

Index of the item to administer, or None when the session has ended: it had already stopped, or the selector had no item to offer, or none the exposure control accepted.

sessionSession

The session to answer the item in: the one given to CatEngine.select(), with the declined items added to its excluded items and, when the selector ran out, its stop_reason set to StopReason.NO_ITEMS.

declinedtuple[int, …]

The items the exposure control declined in this selection, in order (ADR-0011). Each is a proposal that was not administered, so an application that counts proposals adds them and the administered item.
