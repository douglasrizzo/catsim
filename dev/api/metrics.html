Evaluation Metrics – catsim.metrics#

The performance measures of a simulation study, each with its Monte Carlo standard error.

A simulation estimates every measure from a finite number of sessions, so a rerun with another seed gives another value. Each function here returns a Metric: the value, and its Monte Carlo standard error, an estimate of the standard deviation of that value across such reruns [Morris et al., 2019]. A difference between two designs that is small next to their errors cannot be told from noise. SimulationResult computes these measures for a run, overall and by decile of the true ability.

The errors treat the sessions as independent draws, as they are when no session sees exposure rates: every examinee draws from streams of their own (ADR-0013). Under exposure feedback each session depends on the ones before it, so the errors are approximations, and replications of the run give the exact spread (ADR-0016).

class catsim.metrics.Metric(value: T, mc_se: T)[source]#

A performance measure of a simulation run, with its Monte Carlo standard error.

A metric unpacks as a pair, value, mc_se = metrics.bias(true_thetas, thetas). A measure with one value per item, such as the exposure rates, holds one array of values and one of errors.

Parameters:
valuefloat or numpy.ndarray

The measure’s value over the run’s sessions.

mc_sefloat or numpy.ndarray

Its Monte Carlo standard error, NaN where the sessions give no estimate of it, as a single session cannot.

Examples

>>> from catsim.metrics import bias
>>> value, mc_se = bias([0.0, 0.0, 0.0], [0.5, -0.5, 1.5])
>>> value, round(mc_se, 4)
(0.5, 0.5774)

catsim.metrics.bias(true_thetas: npt.ArrayLike, thetas: npt.ArrayLike) → Metric[float][source]#

Return the mean signed error of the ability estimates [Chang et al., 2001], with its Monte Carlo standard error.

\[\mathrm{Bias} = \frac{1}{N} \sum_{j=1}^{N} e_j, \qquad \widehat{\mathrm{SE}}(\mathrm{Bias}) = \sqrt{\frac{1}{N(N-1)} \sum_{j=1}^{N} (e_j - \mathrm{Bias})^2}\]

where \(e_j = \hat{\theta}_j - \theta_j\) is examinee \(j\)’s estimate minus their true ability and \(N\) the number of examinees. A positive bias means the estimates overestimate ability on average, a negative one that they underestimate it. The error is that of the bias in Morris et al. [2019] (Table 6), with \(e_j\) in place of \(\hat{\theta}_i - \theta\), since each examinee has their own true ability: the error of the mean of the errors (mean()).

Parameters:
true_thetasarray-like

The true abilities, finite.

thetasarray-like

The estimated abilities, one per true ability, finite.

Returns:
Metric

The bias and its Monte Carlo standard error, NaN for a single examinee.

Raises:
TypeError

If either input is not one-dimensional or holds values that are not real numbers.

ValueError

If the inputs are empty, differ in length or hold a value that is not finite.

Examples

>>> from catsim.metrics import bias
>>> bias([1.0, -1.0], [0.0, 6.0])
Metric(value=3.0, mc_se=4.0)
catsim.metrics.exposure_rates(counts: npt.ArrayLike, n_sessions: int) → Metric[FloatArray][source]#

Return each item’s exposure rate, the share of a run’s sessions given it, with its Monte Carlo standard error.

\[r_i = \frac{c_i}{N}, \qquad \widehat{\mathrm{SE}}(r_i) = \sqrt{\frac{r_i (1 - r_i)}{N}}\]

where \(c_i\) is the number of sessions that administered item \(i\) and \(N\) the number of sessions. A session gives an item at most once, so a rate is a proportion of the sessions, and its error is the binomial one that Morris et al. [2019] (Table 6) give for coverage and rejection rates. The error is 0 for an item that no session, or every session, was given. The proposal counts of a run give its proposal rates the same way.

Parameters:
countsarray-like

Each item’s count over the run: the sessions that administered it, or that proposed it. Integers from 0 to n_sessions.

n_sessionsint

The number of sessions in the run, positive.

Returns:
Metric

One rate per item, and one Monte Carlo standard error per item, as arrays.

Raises:
TypeError

If counts is not a one-dimensional array of integers, or n_sessions is not an integer.

ValueError

If counts is empty, n_sessions is not positive, or a count is negative or above n_sessions.

Examples

>>> from catsim.metrics import exposure_rates
>>> rates, errors = exposure_rates([4, 1, 0], n_sessions=4)
>>> rates.tolist(), errors.round(4).tolist()
([1.0, 0.25, 0.0], [0.0, 0.2165, 0.0])
catsim.metrics.mean(values: npt.ArrayLike) → Metric[float][source]#

Return the mean of a statistic over a run’s sessions, with its Monte Carlo standard error.

\[\bar{x} = \frac{1}{N} \sum_{j=1}^{N} x_j, \qquad \widehat{\mathrm{SE}}(\bar{x}) = \sqrt{\frac{1}{N(N-1)} \sum_{j=1}^{N} (x_j - \bar{x})^2}\]

where \(x_j\) is session \(j\)’s value and \(N\) the number of sessions. This is the Monte Carlo standard error of a mean, as Morris, White & Crowther give it for the bias (Morris et al. [2019], Table 6) and Siepe et al. for the mean of any statistic (Siepe et al. [2024], Table 3). The mean test length and the mean standard error of a run are such means.

Parameters:
valuesarray-like

One value per session, such as its test length or the standard error of its final estimate.

Returns:
Metric

The mean and its Monte Carlo standard error. The error is NaN for a single session, whose values have no spread to estimate it from, and for values that are not all finite, such as the infinite standard error of a session that ended before its first response, whose mean is infinite.

Raises:
TypeError

If values is not one-dimensional or holds values that are not real numbers.

ValueError

If values is empty or holds NaN.

Examples

Two tests of 10 and 14 items: their deviations from the mean, 12, are -2 and 2, so the error is \(\sqrt{8 / (2 \cdot 1)} = 2\).

>>> from catsim.metrics import mean
>>> mean([10, 14])
Metric(value=12.0, mc_se=2.0)
catsim.metrics.mse(true_thetas: npt.ArrayLike, thetas: npt.ArrayLike) → Metric[float][source]#

Return the mean squared error of the ability estimates [Chang et al., 2001], with its Monte Carlo standard error.

\[\mathrm{MSE} = \frac{1}{N} \sum_{j=1}^{N} e_j^2, \qquad \widehat{\mathrm{SE}}(\mathrm{MSE}) = \sqrt{\frac{1}{N(N-1)} \sum_{j=1}^{N} (e_j^2 - \mathrm{MSE})^2}\]

where \(e_j = \hat{\theta}_j - \theta_j\) is examinee \(j\)’s estimate minus their true ability and \(N\) the number of examinees. Lower values mean more accurate estimates; the MSE is the squared bias() plus the variance of the errors. The error is that of the MSE in Morris et al. [2019] (Table 6), with \(e_j\) in place of \(\hat{\theta}_i - \theta\): the error of the mean of the squared errors (mean()).

Parameters:
true_thetasarray-like

The true abilities, finite.

thetasarray-like

The estimated abilities, one per true ability, finite.

Returns:
Metric

The mean squared error and its Monte Carlo standard error, NaN for a single examinee.

Raises:
TypeError

If either input is not one-dimensional or holds values that are not real numbers.

ValueError

If the inputs are empty, differ in length or hold a value that is not finite.

Examples

>>> from catsim.metrics import mse
>>> mse([1.0, -1.0], [0.0, 6.0])
Metric(value=25.0, mc_se=24.0)
catsim.metrics.overlap_rate(administered_items: npt.ArrayLike, n_items: int) → Metric[float][source]#

Return the test overlap rate of a run’s fixed-length tests, with its Monte Carlo standard error.

The test overlap rate is the share of items that the tests of two examinees have in common, averaged over every pair of examinees [Chen et al., 2003]. For \(N\) tests of \(L\) items each from a bank of \(M\) items, with exposure rates \(r_i\), its large-sample value is

\[T = \frac{1}{L} \sum_{i=1}^{M} r_i^2 = \frac{M}{L} S_r^2 + \frac{L}{M}\]

where \(S_r^2\) is the variance (divisor \(M\)) of the exposure rates (Chen et al. [1999], equations 11 and 14). It is \(L/M\) when every item is equally exposed, and 1 when every examinee takes the same test; higher values mean examinees share more items, which weakens test security. It is the overlap rate of Barrada et al. [2010]. The average over the \(N(N-1)/2\) pairs of distinct examinees is \((N T - 1) / (N - 1)\) (Chen et al. [1999], equation 10), which \(T\) exceeds by \((1 - T) / (N - 1)\).

The Monte Carlo standard error is the delta method’s. \(T\) is a function of the rates, the means over the sessions of each session’s item indicators \(x_j\), and its gradient in them is \(2 r / L\), so

\[\widehat{\mathrm{SE}}(T) = \frac{2}{L} \sqrt{\frac{1}{N(N-1)} \sum_{j=1}^{N} (y_j - \bar{y})^2}, \qquad y_j = r \cdot x_j = \sum_{i \in t_j} r_i\]

where \(y_j\) sums the exposure rates of the items of session \(j\)’s test \(t_j\); \(y_j / L\) is that test’s average overlap with the run’s tests, and \(T\) their mean. Choe and Chang [2019] prove that the average test overlap rate of fixed-length tests is asymptotically normal.

Parameters:
administered_itemsarray-like

The run’s tests, one row per session holding the indices of the items it administered, so every test has the same length. Each row gives an item at most once.

n_itemsint

The number of items in the bank, \(M\).

Returns:
Metric

The overlap rate and its Monte Carlo standard error, NaN for a single session.

Raises:
TypeError

If administered_items is not a two-dimensional array of integers, or n_items is not an integer.

ValueError

If there is no session or the tests have no item, an index is outside the bank, or a session gives an item twice.

Examples

Half the examinees take items 0 and 1 and half items 0 and 2, so a pair shares both items with probability 1/2 and one item otherwise, and the rates are 1, 0.5, 0.5 and 0:

>>> from catsim.metrics import overlap_rate
>>> overlap_rate([[0, 1], [0, 2]], n_items=4).value
0.75
catsim.metrics.rmse(true_thetas: npt.ArrayLike, thetas: npt.ArrayLike) → Metric[float][source]#

Return the root mean squared error of the ability estimates [Barrada et al., 2010], with its Monte Carlo standard error.

\[\mathrm{RMSE} = \sqrt{\mathrm{MSE}}, \qquad \widehat{\mathrm{SE}}(\mathrm{RMSE}) = \frac{\widehat{\mathrm{SE}}(\mathrm{MSE})}{2\,\mathrm{RMSE}}\]

where \(\mathrm{MSE}\) and its error are those of mse(). The RMSE is in the units of the ability scale. Its error follows from the MSE’s by the delta method, since the derivative of \(\sqrt{m}\) is \(1 / (2\sqrt{m})\); it is the error Siepe et al. [2024] give for the RMSE (Table 3). It is 0 when every estimate equals its true ability.

Parameters:
true_thetasarray-like

The true abilities, finite.

thetasarray-like

The estimated abilities, one per true ability, finite.

Returns:
Metric

The root mean squared error and its Monte Carlo standard error, NaN for a single examinee.

Raises:
TypeError

If either input is not one-dimensional or holds values that are not real numbers.

ValueError

If the inputs are empty, differ in length or hold a value that is not finite.

Examples

>>> from catsim.metrics import rmse
>>> rmse([1.0, -1.0], [0.0, 6.0])
Metric(value=5.0, mc_se=2.4)
