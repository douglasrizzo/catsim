Standard Error Stopper#

Motivation#

Variable-length CATs are usually justified by precision: once the current test is informative enough, continuing to administer items yields diminishing returns. The standard-error stopper operationalizes that idea by terminating the test when the standard error of estimation falls to a target value.

This is one of the most common adaptive stopping rules because its threshold is easy to interpret on the theta scale and directly reflects the information accumulated by the current administered set. catR calls it the precision criterion (Magis and Raîche, 2012, p. 10).

Definition#

The stopper judges the standard error the estimator reported with the current estimate, the context’s se (ADR-0004). It stops when

\[SE(\hat{\theta}) \le \tau,\]

where \(\tau\) is the configured max_se. Each estimator computes that error by its own formula, as catR does (Magis and Raîche, 2012, pp. 4-6). For maximum likelihood and the WLE it is the Fisher standard error, \(1/\sqrt{I(\hat{\theta})}\), with \(I(\hat{\theta})\) the information of the administered test at the current estimate. For EAP it is the posterior standard deviation, and for MAP the information plus the prior’s negative curvature. Those two are usually smaller than the Fisher error at the same estimate, so the same threshold ends EAP and MAP tests sooner. Before any response the standard error is infinite, so the test does not stop. A context built by hand, such as one for satisfied() after a run, must pass the session’s current_se as se, whose default is infinite. As in catR, items are administered “until the standard error of the provisional ability estimate gets smaller than or equal to that threshold” (Magis and Raîche, 2012, p. 11).

Samejima (1977, p. 238) suggests terminating an adaptive test when the test information function reaches a criterion value, or equivalently when the standard error of estimation falls to a small value, which can be constant across ability or depend on it; catsim uses a constant. She argues that the standard error, rather than reliability, should be the index of dependability (p. 233).

A target that some examinees cannot reach with the bank keeps their tests going until the bank runs out, so the stopper is usually combined with a MaxLengthStopper cap, and often with a minimum length, in a StopRule (see Combining stopping rules).

Parameters#

Parameter

Default

Description

max_se

required

Largest standard error \(\tau\) at which the test stops. Must be positive.

Behavioral Contracts#

Any correct implementation must satisfy the following properties:

  1. The stopper returns True exactly when the context’s standard error, the one the estimator reported, is at most max_se.

  2. Before any response the standard error is infinite, so the stopper returns False.

  3. A max_se of zero or less raises ValueError.

API Reference#

class catsim.stopping.StandardErrorStopper(max_se: float)[source]#

Bases: BaseStopper

Stop once the standard error of the ability estimate is at most a target value.

The standard error is the one the estimator reported with the current estimate, context.se (ADR-0004): the posterior standard deviation for EAP, the Fisher standard error for maximum likelihood. Before any response it is infinite, so the test does not stop.

Parameters:
max_sefloat

Largest standard error at which the test stops. Must be positive. Smaller values ask for more precision, and so for more items.

Raises:
ValueError

If max_se is not positive (or is NaN).

Notes
