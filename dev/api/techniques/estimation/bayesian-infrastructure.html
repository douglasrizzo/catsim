Bayesian Estimation Infrastructure#

Motivation#

Bayesian estimators and selectors need the same substrate: a prior on \(\theta\), a fixed quadrature grid, and a numerically stable way to turn responses into a discrete posterior. This page specifies that shared subsystem so that later features do not duplicate incompatible posterior code.

The infrastructure is not an estimator by itself. The EAP estimator is built on it, the MAP estimator reuses its prior factories, and the planned posterior-weighted selectors (MPWI, KLP, MEPV) would reuse its posterior.

Definition#

For a response vector \(\mathbf{u}\) on administered items with parameters \(\boldsymbol{\xi}\), the posterior is

\[p(\theta \mid \mathbf{u}) = \frac{p(\theta)\,L(\mathbf{u}\mid\theta)} {\int p(\theta)\,L(\mathbf{u}\mid\theta)\,d\theta}.\]

On a fixed grid \(\{\theta_q\}_{q=1}^{Q}\) with quadrature weights \(\{w_q\}_{q=1}^{Q}\), the discrete approximation is

\[\tilde{p}(\theta_q \mid \mathbf{u}) \propto w_q\,p(\theta_q)\,L(\mathbf{u}\mid\theta_q), \qquad \sum_{q=1}^{Q}\tilde{p}(\theta_q \mid \mathbf{u}) = 1.\]

The log-likelihoods are summed at each node, as Bock and Mislevy (1982, p. 432) recommend for adaptive testing, and the posterior is normalized after subtracting the largest log-posterior value, so long response vectors do not underflow. Downstream techniques reuse the same posterior moments:

\[\hat{\theta}_{\mathrm{EAP}} = \sum_{q=1}^{Q} \theta_q \tilde{p}(\theta_q \mid \mathbf{u}), \qquad \operatorname{Var}(\theta \mid \mathbf{u}) = \sum_{q=1}^{Q}(\theta_q-\hat{\theta}_{\mathrm{EAP}})^2 \tilde{p}(\theta_q \mid \mathbf{u}).\]

These are Equations 4 and 5 of Bock and Mislevy (1982, p. 433), without the square root on the variance; they credit the quadrature formulas to Bock and Aitkin (1981) (p. 432). Like Bock and Mislevy, catsim uses evenly spaced nodes rather than Gauss–Hermite points, which offer little advantage here because the likelihood is not a polynomial (p. 433).

By default the grid has 121 equally spaced nodes on \([-6, 6]\) (spacing 0.1) and the prior is \(\mathcal{N}(0, 1)\).

Grid resolution#

The grid is accurate while it resolves the posterior. Compared with a 2,401-node reference, the default grid reproduces the posterior mean and standard deviation to within about 0.25% while the posterior standard deviation is at least 0.065, which takes a test information of about 240. Below that it degrades: errors reach about 6% at a posterior standard deviation of 0.05 and about 44% at 0.035. The default follows the advice of Bock and Mislevy (1982, p. 433), who suggested about 80 points between \(\pm 4\) standard deviations, also a spacing of 0.1, to keep precision down to a posterior standard deviation of 0.2. A coarser grid degrades sooner: with 41 nodes (spacing 0.3), errors reach about 7% at a posterior standard deviation of 0.15 and about 44% at 0.11. EAPEstimator reports the posterior standard deviation as its standard error, so a precision stopper with a threshold below about 0.065 needs a finer grid than the default.

Bock and Mislevy also applied Sheppard’s correction to the posterior variance (p. 433). catsim does not: the nodes are evaluated rather than grouped, so the uncorrected moments already match the reference above, and the correction would shrink the standard deviation by about 1% at a posterior standard deviation of 0.2 and by about 9% at 0.07.

Behavioral Contracts#

Any correct implementation must satisfy the following properties:

  1. The posterior probabilities on the quadrature grid sum to 1 after normalization.

  2. The posterior computation is numerically stable on long response vectors; it must not return NaNs or all-zero weights solely due to exponentiation underflow.

  3. With an empty response vector, the posterior reduces to the normalized prior multiplied by the grid weights.

  4. Posterior mean and posterior variance are computed from the same normalized discrete posterior and therefore remain internally consistent.

  5. As informative items accumulate, posterior variance should generally contract rather than expand without bound.

API Reference#

class catsim.estimation.QuadratureGrid(nodes: NDArray[floating[Any]], weights: NDArray[floating[Any]])[source]#

Bases: object

A fixed quadrature grid for posterior computations.

The posterior at node \(\theta_q\) is proportional to \(w_q\,p(\theta_q)\,L(\mathbf{u} \mid \theta_q)\), so the weights take part in the posterior itself. Equal weights, as built by uniform(), cancel in the normalization. Two grids are equal only if they are the same object, and a grid can be a set member or a dictionary key.

For the full posterior specification and quadrature contract, see Bayesian Estimation Infrastructure.

Parameters:
nodesnumpy.ndarray

One-dimensional array of finite ability values.

weightsnumpy.ndarray

One-dimensional array of finite, positive quadrature weights, one per node.

Raises:
ValueError

If the arrays are not one-dimensional, differ in length, have fewer than two entries, or hold non-finite nodes or non-positive weights.

catsim.estimation.posterior(responses: Sequence[bool], items: NDArray[floating[Any]], grid: QuadratureGrid, log_prior: Callable[[NDArray[floating[Any]]], NDArray[floating[Any]]]) → NDArray[floating[Any]][source]#

Compute the normalized discrete posterior over grid.nodes.

Each node gets mass proportional to \(w_q\,p(\theta_q)\,L(\mathbf{u} \mid \theta_q)\), computed in log space and shifted by its maximum before exponentiating, so the likelihood of many responses does not underflow.
