Maximum Expected Information Selector#

Motivation#

Maximum-information selectors look only at the present estimate. MEI instead asks which candidate item is expected to produce the most informative next test state after the next response is observed.

That one-step-ahead view makes MEI stronger than plain Fisher selection in cases where the current estimate is likely to move substantially after the next item. It is therefore a forward-looking selector rather than a purely local one.

Definition#

For candidate item \(i\), let \(P_i(\hat{\theta})\) be the probability of a correct response at the current estimate. Let \(\hat{\theta}_i^{(1)}\) and \(\hat{\theta}_i^{(0)}\) be the updated ability estimates after a hypothetical correct or incorrect response to item \(i\). Then

\[\mathrm{MEI}_i = P_i(\hat{\theta})\,I(\hat{\theta}_i^{(1)}) + [1-P_i(\hat{\theta})]\,I(\hat{\theta}_i^{(0)}),\]

where \(I(\cdot)\) is the information of the administered test extended by the candidate item. The selector chooses the non-administered item with the largest expected information value.

van der Linden’s 1996 report, which preceded the 1998 article, defines MEI with the observed information of the whole response pattern, the administered items plus the candidate’s predicted response, each evaluated at its updated estimate, and weights the two branches by the response probabilities at the current estimate (p. 11, Equation 13). He notes that the criterion therefore re-evaluates the information of the items already administered. Choi and Swartz (2009, Equation 3, extended to polytomous items) use the same whole-pattern measure. catsim follows this definition with Fisher instead of observed information; the two are equal under the 2PL model the report assumes (p. 10) and differ with guessing or slipping.

catR departs from it: its MEI.R uses only the candidate item’s information at each updated estimate (Magis & Raîche, 2012, p. 9, Table 1), observed information by default (p. 17). The two forms can rank items differently.

With the default estimator (maximum likelihood with Dodd’s heuristic), while the responses so far are all correct, the hypothetical correct branch is still an all-correct pattern, so Dodd’s heuristic returns the same updated estimate for every candidate; the same happens on the incorrect branch while all responses are incorrect. On that branch the look-ahead is a fixed jump rather than an estimate. Bayesian estimators and WLE give a genuine updated estimate on both branches from the first item.

Parameters#

Parameter

Default

Description

estimator

NumericalSearchEstimator()

Estimator used to compute the hypothetical one-step-ahead ability updates. Any estimator can be passed; EAP, MAP or WLE avoid the limitation described above. It may be the engine’s own estimator: the selector reads only .theta from its look-ahead estimates, and the session never records them.

r_max

1.0

Maximum exposure rate, in \((0, 1]\). Items at or above it are left out before the expected information is computed, unless every remaining item is.

Behavioral Contracts#

Any correct implementation must satisfy the following properties:

  1. The score for each candidate equals \(P\,I_{\text{correct}} + (1-P)\,I_{\text{incorrect}}\) under the configured estimator.

  2. Each one-step-ahead update starts from the session’s observed responses, which the selector reads from its context, plus one hypothetical response to the candidate.

  3. On at least some banks, MEI must differ from plain maximum-information selection; otherwise it is not implementing the forward-looking criterion.

  4. Both hypothetical response branches for every candidate item are evaluated before selection.

  5. Exposure filtering applies to the candidate set before the final argmax, with the same no-items behavior as other selectors.

API Reference#

class catsim.selection.MEISelector(estimator: BaseEstimator | None = None, r_max: float = 1.0)[source]#

Bases: BaseSelector

Maximum Expected Information selector.

For each candidate item, the selector re-estimates ability as if the candidate were answered correctly and as if it were answered incorrectly. It scores the candidate by the information of the administered test plus the candidate at each updated estimate, weighted by the probability of each response at the current estimate, and selects the highest score.

Parameters:
estimatorBaseEstimator or None, optional

Estimator used for the one-step-ahead ability updates. Default is a new catsim.estimation.NumericalSearchEstimator. It may be the engine’s own estimator: the look-ahead estimates are never recorded in the session.

r_maxfloat, optional

Maximum exposure rate for items. Items with exposure rates >= r_max are only selected when no other item remains. Default is 1 (no restriction).

Notes

For full algorithmic details, see Maximum Expected Information Selector.
