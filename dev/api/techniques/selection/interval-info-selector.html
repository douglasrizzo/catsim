Interval Information Selector#

Motivation#

Point-information rules assume the current estimate is accurate enough to be trusted as a single design point, which is least true early in the test. The interval information criterion of Veerkamp and Berger (1997) instead integrates each item’s information over a confidence interval for \(\theta\). Page and equation numbers below are those of the openly available 1994 research report that preceded the article; there the criterion is one case of a general weighted information criterion, \(\max_i \int W_n(\theta)\, I_i(\theta)\, d\theta\) (p. 7, Equations 7 and 8). The interval is wide while the estimate is uncertain and narrows as items are administered, so the rule moves from favoring broadly informative items towards local maximum-information selection.

Definition#

For an interval \([\theta_L, \theta_U]\), each non-administered item \(i \in R_k\) is scored by

\[S_i = \int_{\theta_L}^{\theta_U} I_i(\theta)\,d\theta, \qquad i^* = \arg\max_{i \in R_k} S_i\]

(p. 10, Equation 14). Dividing by the interval’s length would give a mean information, but the length is the same for every item.

By default the interval is the confidence interval of the maximum-likelihood estimate, using the information \(I(\hat{\theta})\) of the administered items:

\[[\theta_L, \theta_U] = \left[\hat{\theta} - \frac{\lambda}{\sqrt{I(\hat{\theta})}},\; \hat{\theta} + \frac{\lambda}{\sqrt{I(\hat{\theta})}}\right], \qquad \lambda = \Phi^{-1}\left(\frac{1 + \gamma}{2}\right),\]

where \(\gamma\) is the confidence level (p. 9, Equation 11). Equation 12 gives an EAP version, with the posterior standard deviation in place of \(I(\hat{\theta})^{-1/2}\); catsim always uses Equation 11, with the information at the current estimate, whatever estimator produced it. Before any item is administered the interval is the whole ability scale (p. 11, Equation 16). With a fixed interval \(\delta\), the interval is \([\hat{\theta} - \delta, \hat{\theta} + \delta]\) throughout the test.

The integral has a closed form (see catsim.irt.inf_integral()). Since \(dP/d\theta = a (P - c)(d - P)/(d - c)\), substituting \(P\) for \(\theta\) gives

\[\int I_i(\theta)\,d\theta = \frac{a_i}{d_i - c_i}\Big[P - c_i d_i \log P + (1 - c_i)(1 - d_i)\log(1 - P)\Big],\]

so the scores of all items are computed exactly, without numerical quadrature. This extends the 3PL closed form of Veerkamp and Berger (pp. 21–22, Appendix, Equation 25), to which it reduces when \(d_i = 1\). Under the 2PL model, the integral over the whole scale is \(a_i\) (Equation 28).

Behavioral Contracts#

Any correct implementation must satisfy the following properties:

  1. Each candidate score is the integral of the item information function over the interval.

  2. With interval=None, the interval is \(\hat{\theta} \pm \lambda / \sqrt{I(\hat{\theta})}\) for the administered items, and the whole ability scale before any item is administered.

  3. With a fixed interval, the interval is \(\hat{\theta} \pm \delta\).

  4. It never returns an already administered item.

  5. If no non-administered items remain, it raises NoItemsAvailableError.

API Reference#

class catsim.selection.IntervalInfoSelector(interval: float | None = None, confidence: float = 0.95)[source]#

Bases: BaseSelector

Select the item whose information, integrated over an interval around the estimate, is largest.

By default the interval is the confidence interval of the interval information criterion [Veerkamp and Berger, 1997], which narrows as the test information grows:

\[\arg\max_{i \in R} \int_{\theta_L}^{\theta_U} I_i(\theta)\, d\theta, \qquad \theta_{L, U} = \hat\theta \mp \frac{\lambda}{\sqrt{I(\hat\theta)}}, \qquad \lambda = \Phi^{-1}\left(\frac{1 + \gamma}{2}\right)\]

where \(I(\hat\theta)\) is the information of the administered items and \(\gamma\) the confidence level. A fixed half-width \(\delta\) can be used instead.

Parameters:
intervalfloat or None, optional

Fixed half-width \(\delta\) of the interval. Default is None, which uses the confidence interval above.

confidencefloat, optional

Confidence level \(\gamma\) of the default interval. Default is 0.95.

Notes

For full algorithmic details, see Interval Information Selector.
