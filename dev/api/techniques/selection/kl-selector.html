Kullback-Leibler Selector#

Class:

catsim.selection.KLSelector

Sources:

Chang and Ying [1996]

Motivation#

Maximum Fisher information is a local criterion: it trusts the current ability estimate completely. Early in a CAT, that estimate is noisy, so selecting items only by information at a single point can be brittle.

The KL selector takes a global view. It integrates a Kullback-Leibler divergence over a shrinking window around the current estimate, so the method behaves more globally early in the test and more locally later on.

Definition#

For candidate item \(i\), current estimate \(\hat{\theta}\), and a comparison point \(\theta\), the item-level divergence [Chang and Ying, 1996, p. 217, Definition 2.1] is

\[K_i(\theta \,\|\, \hat{\theta}) = P_i(\hat{\theta}) \log \frac{P_i(\hat{\theta})}{P_i(\theta)} + [1-P_i(\hat{\theta})] \log \frac{1-P_i(\hat{\theta})}{1-P_i(\theta)}.\]

It is nonnegative, zero when the two abilities coincide, and its curvature there is the Fisher information (p. 219, Equation 16). The global criterion integrates this divergence over a symmetric window (pp. 219–220, Equation 17):

\[K_i(\hat{\theta}) = \int_{\hat{\theta}-\delta_n}^{\hat{\theta}+\delta_n} K_i(\theta \,\|\, \hat{\theta})\,d\theta, \qquad \delta_n = \frac{c}{\sqrt{n}},\]

where \(n\) is the number of administered items and \(c\), the window parameter, is a positive schedule constant. For a small window the criterion is governed by the curvature, that is, by the Fisher information; for a large one, by the tails of the divergence (p. 220). Before the first item, catsim uses \(n = 1\), so the window is \(\hat{\theta} \pm c\). Chang and Ying also define a Bayesian version that weights the divergence by the posterior (p. 222), KLP, a planned technique. The selector chooses the item, neither administered nor excluded, with the largest value of \(K_i(\hat{\theta})\).

Computation#

Each integral is computed with a Gauss-Legendre rule over the window, the same rule for every candidate. A steep item’s divergence changes quickly near its difficulty, so the rule’s number of nodes is four times the largest discrimination among the candidates times the half-width \(\delta_n\), at least 24 and at most 240. Banks drawn by ItemBank.generate with the default window need 24 to 28 nodes. Up to \(a\,\delta_n = 60\), for example \(a = 10\) over \(\hat{\theta} \pm 6\), every integral above \(10^{-5}\) is within a relative \(10^{-10}\) of adaptive quadrature: at most \(7 \times 10^{-11}\) over 2PL and 4PL items with \(c \leq 0.3\) and \(d \geq 0.85\). Beyond that the rule keeps 240 nodes and the error grows, to about \(2 \times 10^{-7}\) at \(a\,\delta_n = 120\).

Parameters#

Parameter

Default

Description

window

3.0

Positive constant \(c\) controlling the half-width \(\delta_n = c/\sqrt{n}\). Chang and Ying [1996] chose \(c\) from the coverage probability of a confidence interval for \(\theta\) (p. 221) and used \(c = 3\) in their simulation (p. 223).

r_max

1.0

Maximum exposure rate, in \((0, 1]\). Items at or above it are left out before the KL scores are computed, unless every remaining item is.

Behavior and Comparison#

Since the window narrows as \(1/\sqrt{n}\), the criterion comes to be governed by the curvature of the divergence as the test goes on, and its choices approach those of the maximum-information selector.

Comparison with catR

catR’s nextItem with criterion = "KL" departs from this definition: it weights the divergence by the likelihood of the responses so far and integrates it over its whole grid, parInt, by default 33 nodes on \([-4, 4]\) (nextItem.R). catsim integrates the divergence unweighted over the window, the index of Chang and Ying [1996, pp. 219–220, Equation 17], and no KLSelector setting weights it. The parity tests (ADR-0020) therefore compare the integral itself: over catsim’s window, catR’s KL() with the likelihood set to 1 gives catsim’s values and ranking in five contexts, one of which picks another item under the windows of one item more or one item fewer. catR’s own KL ranking, in a context after two responses, differs, and the tests keep it as an expected failure.

Guarantees#

  1. It never returns an item that was already administered or excluded.

  2. When every remaining item is at or above the exposure cap, it falls back to the remaining item with the largest KL integral.

  3. When no item remains, it raises NoItemsAvailableError.

API Reference#

class catsim.selection.KLSelector(window: float = 3.0, r_max: float = 1.0)[source]#

Bases: BaseSelector

Select the item with the most Kullback-Leibler information around the current estimate.

Each candidate item’s KL divergence between the response distributions at the estimate and at nearby abilities is integrated over a window around the estimate, which narrows as items are administered, and the item with the largest integral is selected.

Parameters:
windowfloat, optional

Chang and Ying’s constant \(c\), the half-width of the integration window before it narrows as items are administered. Default is 3.

r_maxfloat, optional

Maximum exposure rate for items. Items with exposure rates >= r_max will not be selected unless no other items are available. Default is 1 (no restriction).

Raises:
ValueError

If window is not positive, or if r_max is not in (0, 1].

Notes

For full algorithmic details, see Kullback-Leibler Selector.
