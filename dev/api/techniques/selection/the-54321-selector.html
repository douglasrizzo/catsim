54321 Selector#

Specification#

Under maximum-information selection every examinee starts from the same ability estimate, so the opening items of every test are the same few items. The 5-4-3-2-1 technique of McBride and Martin (1983) randomizes only those opening items:

  • the first item is drawn uniformly at random from the 5 most informative items at the current estimate;

  • the second from the 4 most informative remaining items;

  • the third from 3 and the fourth from 2;

  • from the fifth item on, the most informative remaining item is administered.

This is the schedule described by Georgiadou et al. (2007, p. 9) in their review of exposure-control strategies. Magis and Raîche (2012, p. 12) list the technique among the methods that choose at random among several near-optimal items, without defining it.

With initial_bin_size \(n\), the item at 0-indexed test position \(k\) is drawn from the \(\max(1, n - k)\) most informative non-administered items, plus any item tied in information with the last of them (ADR-0008: Break Ties Between Items Uniformly at Random). Unlike the randomesque selector, which keeps drawing from a fixed number of items for the whole test (Georgiadou et al., 2007, p. 9), the late items, which matter most for precision, are chosen by maximum information.

Behavioral Contracts#

Any correct implementation must satisfy the following properties:

  1. It never returns an already administered item.

  2. The item at position \(k\) is drawn with the configured random number generator from the \(\max(1, n - k)\) most informative non-administered items.

  3. From position \(n - 1\) on, it returns the most informative non-administered item.

  4. If no non-administered items remain, it raises NoItemsAvailableError.

  5. It applies no exposure cap: it ignores the context’s exposure_rates.

API Reference#

class catsim.selection.The54321Selector(initial_bin_size: int = 5)[source]#

Bases: BaseSelector

Implementation of the 5-4-3-2-1 selector proposed by [McBride and Martin, 1983].

The first item is drawn at random from the 5 most informative items at the current \(\hat\theta\), the second from the 4 most informative remaining items, and so on, so that from the fifth item on the most informative item is administered. Randomizing the opening items, which every examinee would otherwise share while \(\hat\theta\) is still rough, reduces their exposure at little cost in precision. Items tied with the least informative item of a bin also join it, so from the fifth item on, ties for the most information are broken uniformly at random (ADR-0008). The selector applies no exposure cap: context.exposure_rates is ignored.

Parameters:
initial_bin_sizeint, optional

Number of most informative items the first item is drawn from; each following item draws from one fewer. Default is 5.

Notes

For full algorithmic details, see 54321 Selector.
