catsim - Computerized Adaptive Testing Toolkit#

catsim computes and evaluates computerized adaptive tests based on item response theory: it chooses each examinee’s next item from an item bank, estimates the examinee’s ability after each response and decides when the test ends, and it runs simulation studies that compare the methods for each of these steps.

This version breaks code written for catsim 0.21.0 and earlier

That code needs changes to run, and seeded simulations give different numbers. To keep using it, install catsim==0.21.0, documented at the 0.21.0 tag. The release notes list every change.

Run a simulation study#

Researchers compare methods on simulated examinees: Running Simulations builds a test, runs it and reads its metrics, and Reproducibility seeds a study so that it repeats.

Write a strategy#

Method authors add a method of their own: Extending catsim writes one strategy of each kind and says what each must do.

Embed catsim in an application#

Developers let catsim compute each step of their application’s tests: Embedding catsim runs a test step by step and says what the application owns.
