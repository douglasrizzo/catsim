Technique Specifications
########################

This section contains algorithmic specifications for the CAT techniques implemented
in — or planned for — :mod:`catsim`. Each spec describes the motivation, mathematical
definition, parameters, and behavioral contracts for one technique.

For the API reference (class signatures, method descriptions, and usage examples),
see the :doc:`/selection`, :doc:`/estimation`, and :doc:`/stopping` pages.
