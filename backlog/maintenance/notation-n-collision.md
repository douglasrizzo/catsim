# Resolve N, the number of examinees and the planned test length

## The question

"Terms and notation" uses $N$ for the number of examinees. The progressive and proportional selector
pages, and ADR-0019, write the planned test length as $N$, which is Barrada et al.'s notation.

## Options

1. **Keep Barrada's $N$ on those pages,** and add a sentence that says it is the planned test length
   there.
2. **Write the planned test length with catsim's symbol** on those pages, if the terms page has one
   (check), and say once that Barrada et al. write it $N$.
3. **Add a symbol for the planned test length** to the terms page, and use it everywhere.

Recommendation: option 2, or option 3 if the terms page has no symbol for it. One symbol per
quantity is the terms page's job.
