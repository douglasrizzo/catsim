# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/douglasrizzo/catsim/security/advisories/new)
(the repository's **Security** tab, then **Report a vulnerability**). Do not open a public issue or
pull request for them.

Include the catsim version you used, a description of the problem and, if you can, the steps or a
short script that reproduce it.
